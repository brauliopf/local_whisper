# Backend module

## Local development

From this directory:

```sh
cp .env.example .env
# Set OPENAI_API_KEY and SERVICE_TOKEN in .env.
# TYPESAFE_API_KEY is optional.
npm install
npm test
npm run dev
```

The development server listens on `http://127.0.0.1:8080` by default. `npm test` compiles TypeScript into `dist/` and runs the compiled Node test files. `npm run build` only compiles, while `npm start` runs the compiled server.

Never commit `.env` or place secrets in source files, deployment commands, logs, or curl examples. Use test doubles rather than provider credentials in tests.

## Configuration

Configuration is loaded by `src/config.ts` and validated at startup:

- `OPENAI_API_KEY` — required provider credential.
- `SERVICE_TOKEN` — required application bearer token. The macOS app sends this value in the `Authorization` header; the backend compares a SHA-256 digest using a timing-safe comparison.
- `TYPESAFE_API_KEY` — optional. When blank, the transcription workflow translates every non-empty transcript instead of performing Jev classification.
- `PORT` — defaults to `8080`.
- Model variables: `IMAGE_TEXT_MODEL`, `ENCOURAGEMENT_MODEL`, `TRANSCRIPTION_MODEL`, `TRANSLATION_MODEL`, and `TYPESAFE_MODEL` have defaults in `src/config.ts`.
- Limits and timeouts: `IMAGE_MAX_BYTES`, `AUDIO_MAX_BYTES`, `REQUEST_BODY_MAX_BYTES`, provider/overall timeout variables, `TRANSCRIPT_MAX_CHARS`, `RATE_LIMIT_MAX`, and `RATE_LIMIT_WINDOW_MS` also have defaults in `src/config.ts`.

Use `.env.example` as the complete configuration reference.

## Source map

- `src/server.ts` — Loads configuration, constructs providers and the transcription workflow, and starts Fastify.
- `src/config.ts` — Environment parsing, required secrets, defaults, and validation.
- `src/app.ts` — Fastify routes, bearer authentication, multipart validation, request limits, rate limiting, deadlines, and API error mapping.
- `src/provider.ts` — OpenAI-backed provider implementation and provider error handling.
- `src/transcription.ts` — Transcription, language classification, translation, cancellation, timeout, and transcript-length workflow.
- `src/typesafe.ts` — TypeSafe Jev client used for majority-English classification.
- `src/prompts.ts` — Backend-owned prompts.
- `src/rate-limit.ts` — In-memory fixed-window rate limiter.
- `src/errors.ts` — Public API error types.
- `src/*.test.ts` — Node test-runner coverage for configuration, routes, errors, and transcription behavior.

`dist/` is generated by TypeScript compilation. Edit files under `src/`, not generated JavaScript under `dist/`.

## API behavior

- `GET /status` is unauthenticated and reports only provider configuration status.
- `POST /image-text` accepts exactly one JPEG or PNG multipart file named `image`.
- `POST /transcriptions` accepts exactly one M4A multipart file named `audio`.
- `POST /encouragements` accepts an empty JSON object and returns one short sentence.
- Successful operation responses include a `request_id`; transcription responses may also include `is_translated`.
- Client cancellation and provider/request deadlines abort work. Empty transcription output skips classification and translation.
- The backend validates media headers, enforces size limits, applies an in-memory rate limit, and avoids returning provider credentials or raw provider errors to clients.

The macOS client is implemented in `../local_whisper/Shared/Backend/BackendClient.swift`. Keep endpoint names, multipart field names, response keys, and authentication behavior compatible with that client.
